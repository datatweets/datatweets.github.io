dbt for Data Engineers

Learn dbt for real, local analytics engineering — install dbt Core, stand up a Postgres warehouse in Docker, and transform CityFlow's real trip data through staging, testing, and marts, up through incremental models, snapshots, and a real capstone.

Get started Browse all courses

Cost

What you'll build

All 12 modules live: rejoin CityFlow and feel why loading data before transforming it (ELT) is a genuinely different discipline than the ETL scripts earlier courses in this path wrote, then install dbt Core 1.12 against a real Postgres 16 warehouse in Docker (no cloud account, no dbt Cloud subscription) and build up through ref()/source() and materializations, a tested staging layer, real marts (linking into this site's own DuckDB course with a second-warehouse adapter swap), Jinja macros and dbt_utils, incremental models handling a 9.5-million-row history, SCD Type 2 snapshots, full project documentation and lineage, and dbt's own unit tests catching what data tests can't — then deployment: isolated dev/prod/Airflow environments, state-based selection, a CI gate, and a scheduled Airflow DAG (linking into Orchestrating Data Pipelines with Airflow).

The course closes with a capstone: CityFlow's entire warehouse rebuilt from an empty Postgres schema in one unrestricted dbt build, fully tested and documented, orchestrated by a two-task Airflow DAG that checks its own result — reconciled to the exact 240,917 zone-hour buckets, 9,554,757 trips, $256,692,373.14 this site's other Data Engineering courses already established, this time built entirely in SQL.

Before you start

What you'll be able to do

  • Install and run dbt Core against a real Postgres warehouse in Docker
  • Build staging, intermediate, and mart models linked by ref() and source()
  • Test and document data with dbt's own generic, singular, and unit tests
  • Build incremental models and snapshots, and orchestrate dbt with Airflow

Prerequisites

  • No prior dbt experience required — this course teaches it from the first model
  • SQL fluency (SELECT, JOIN, GROUP BY) — this site's own SQL course covers it
  • A working command line
  • Docker Desktop (or Docker Engine on Linux), covered in Module 1

Tools you'll use

  • dbt Core
  • Docker
  • Postgres
  • Python
  • Airflow

Before you start

SQL fluency (SELECT, JOIN, GROUP BY) is assumed — this site's own SQL course covers it. No prior dbt experience is required, and this is the sixth course in this site's Data Engineering path (alongside Scaling Python, PySpark, Docker & Kubernetes, Airflow, and Apache Kafka). You can start here fresh; later modules cross-link into the others where it's genuinely useful, never as a hard requirement.

Set up your environment

Everything in this course runs for real, locally, on your own machine — no cloud account, nothing to pay for.

  1. Docker Desktop (or Docker Engine on Linux) — a single install, running a real Postgres warehouse for the rest of the course.
  2. Python 3.10 or newer — dbt Core itself, plus this course's own loader scripts.

Every command and every piece of output you see was actually run against the real, installed platform — nothing is simulated or invented.
