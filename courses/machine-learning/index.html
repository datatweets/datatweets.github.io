Before you start

What you'll be able to do

  • Build, evaluate and tune supervised models for regression and classification
  • Engineer features and optimise models rather than accepting the first result
  • Apply tree ensembles and unsupervised methods to real datasets
  • Train neural networks in both PyTorch and TensorFlow
  • Work with images, sequences and text using CNNs, RNNs and modern NLP

Prerequisites

  • Comfortable with Python, NumPy and pandas — our Python for Data Analytics course covers these
  • The opening Math Foundations module supplies the calculus and linear-algebra intuition; skip it if you already have that

Tools you'll use

  • scikit-learn
  • pandas
  • NumPy
  • PyTorch
  • TensorFlow
  • Matplotlib

Before you start

This course assumes you are comfortable with Python, NumPy, and Pandas. If you need them first, work through our Python for Data Analytics course, then come back here.

The path opens with a Math Foundations module — the calculus and linear algebra intuition the algorithms rely on. Start there for the full journey, or jump straight to the ML workflow if you are already comfortable with derivatives, vectors, and matrices.
