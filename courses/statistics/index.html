Before you start

What you'll be able to do

  • Describe a dataset honestly with the right measures of centre and spread
  • Reason about probability, independence and conditional probability
  • Apply Bayes' theorem to update a belief as evidence arrives
  • Draw conclusions from a sample and state how confident you're entitled to be

Prerequisites

  • Comfortable with basic Python — you'll run the calculations rather than do them by hand
  • School-level algebra; no calculus required

Tools you'll use

  • Python 3
  • pandas
  • NumPy
  • SciPy

What you'll build: 5 hands-on project lessons you write yourself.

Datasets used in this course

Three real datasets recur throughout the lessons, so every statistic comes from data you can download and reproduce yourself.

  • penguins.csv
    Palmer Archipelago penguin measurements — used for distributions, probability, and Bayes.
  • cars.csv
    1970s–80s automobile fuel economy — used for center, spread, z-scores, and inference.
  • headlines.csv
    Labeled clickbait vs. genuine headlines — used to build the Naive Bayes classifier.
