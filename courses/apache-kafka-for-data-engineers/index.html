Apache Kafka for Data Engineers

Learn Apache Kafka for real, local event streaming — install it, produce and consume real messages, and build up to Schema Registry, Kafka Connect, stream processing, and a real capstone.

Get started Browse all courses

At a glance

Level
Beginner to Advanced
Lessons
56 lessons across 12 modules
What you build
A real 3-broker Kafka cluster streaming CityFlow's trip events — more modules on the way
Cost
100% free · runs entirely on your own laptop, no cloud account

What you'll build

All 12 modules live: rejoin CityFlow and feel the real coupling problem a message broker solves, then install a genuine 3-broker Apache Kafka 4.0 cluster in KRaft mode (no ZooKeeper, no cloud account) and build up through topic design, producers, consumers and consumer groups, cluster internals and failure recovery, reliable delivery, Schema Registry and data contracts, Kafka Connect (linking into this site's SQL course), stream processing with Faust and Spark Structured Streaming (linking into PySpark for Data Engineering), orchestration and monitoring with Airflow (linking into Orchestrating Data Pipelines with Airflow), and cross-cluster replication and architecture.

The course closes with a capstone: CityFlow's real-time event platform, validated against a real Avro schema, processed live with Faust, sunk to a real database and search index via Kafka Connect, monitored for lag, and orchestrated by a real Airflow DAG — verified end to end against the exact trip-count and revenue figures this site's other Data Engineering courses already established.

Before you start

What you'll be able to do

  • Install and run a real 3-broker Apache Kafka 4.0 cluster in KRaft mode
  • Produce and consume real events, with consumer groups and reliable delivery
  • Enforce data contracts with Schema Registry, and move data with Kafka Connect
  • Process streams in real time with Faust and Spark Structured Streaming

Prerequisites

  • No prior Kafka experience required — this course teaches it from the first message
  • Basic Python — reading a script, running it, and managing basic dependencies
  • A working command line
  • Docker Desktop (or Docker Engine on Linux), covered in Module 1

Tools you'll use

  • Apache Kafka
  • Docker
  • Python
  • Schema Registry
  • Kafka Connect

What you'll build: 12 hands-on project lessons you write yourself, ending in a capstone.

Before you start

No prior Kafka, SQL, Spark, or Airflow experience is required — this course teaches what it needs as it goes, and is the fifth course in this site's Data Engineering path (alongside Scaling Python, PySpark, Docker & Kubernetes, Airflow, and dbt). You can start here fresh; later modules cross-link into the others where it's genuinely useful, never as a hard requirement.

Set up your environment

Everything in this course runs for real, locally, on your own machine — no cloud account, nothing to pay for.

  1. Docker Desktop (or Docker Engine on Linux) — a single install, running a real 3-broker Kafka cluster throughout the course.
  2. Python 3.9 or newer — this course's producer, consumer, and stream-processing code is Python throughout.

Every command and every piece of output you see was actually run against the real, installed platform — nothing is simulated or invented.
