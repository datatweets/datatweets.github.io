Streamlit for Data Apps

Learn Streamlit for real, hands-on data apps — install it, build your first interactive tool, and grow one real dashboard over real Gapminder data through visualization, layout, testing, presentation, and a live deployment.

What you'll build

You'll build the World Development Explorer, one real Streamlit app that grows module by module over real Gapminder Foundation data — country-level life expectancy, population, and GDP per capita from 1952 to 2007. It starts as a five-line script and grows into a real multi-page dashboard: loading and caching the data, a real filter panel, interactive Plotly and Altair charts, a choropleth map, a proper multi-page layout with forms and file uploads, an automated AppTest test suite, a caching and performance pass, real presentation tools (matplotlib/seaborn, CSV exports, custom theming, LaTeX), and a real deployment to Streamlit Community Cloud that anyone can open in a browser. The capstone assembles every piece into one finished, tested, presentable, deployable app.

Before you start

What you'll be able to do

  • Build and run real Streamlit apps, and explain precisely why the whole script reruns on every interaction
  • Load, cache, filter, and visualize real data with Plotly, Altair, and Streamlit's own chart functions
  • Structure a real multi-page app with forms, file uploads, and current navigation patterns
  • Test a Streamlit app with AppTest, tune its performance, and deploy it live to Streamlit Community Cloud
  • Present real work with matplotlib/seaborn charts, CSV exports, custom theming, and LaTeX math notation

Prerequisites

  • Basic Python — variables, functions, and reading a pandas DataFrame; every Streamlit-specific idea is explained the first time it appears
  • No prior web development experience required — no HTML, CSS, or JavaScript anywhere in this course
  • A working command line and a code editor

Tools you'll use

  • Streamlit
  • Python
  • Pandas
  • Plotly
  • Altair
  • Matplotlib / Seaborn

Before you start

You need basic Python — variables, functions, and reading a pandas DataFrame — and nothing else. No prior web development is required: this course never touches HTML, CSS, or JavaScript directly, since that's the entire point of Streamlit. A working command line and a code editor are all the setup you need.

Set up your environment

Everything in this course runs for real, locally, on your own machine — no cloud account required until the deployment lesson in Module 5, and that step is free too.

  1. Python 3.10+ — already on most systems; verified in Module 1.
  2. Streamlit — a single pip install streamlit, covered fully in Lesson 1.

Every app, every command, and every piece of output you see was actually run — nothing is simulated or invented. Verified against Streamlit 1.62 as of August 2026; if a newer version changes something, this course names the difference rather than let it go stale silently.
