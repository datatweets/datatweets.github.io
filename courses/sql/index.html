Before you start

What you'll be able to do

  • Write SQL that selects, filters, sorts and aggregates data in a real database
  • Combine tables with joins, and express harder questions with subqueries, CTEs and views
  • Rank, compare and window over rows without leaving SQL
  • Design, load and administer PostgreSQL, then tune slow queries with indexes
  • Query databases from Python directly and through SQLAlchemy

Prerequisites

  • No prior SQL required — the course begins with your first query
  • Basic Python is useful for the final modules, but not for the first two-thirds

Tools you'll use

  • PostgreSQL
  • psql
  • psycopg2
  • SQLAlchemy
  • pandas

What you'll build: 6 hands-on project lessons you write yourself.
