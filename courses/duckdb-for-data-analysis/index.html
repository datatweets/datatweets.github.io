DuckDB for Data Analysis

Learn DuckDB for fast, local SQL analytics — install it, query a CSV file directly with no load step, and build up to joins, JSON, remote data, dashboards, and a real capstone.

What you'll build

You'll work with Thistlewood Goods, a small home-goods retailer, building one real analytics pipeline that grows module by module: installing the DuckDB CLI and Python API and running SQL directly against a real CSV file with no separate load step, filtering, sorting, aggregating, and joining the DuckDB way, reading CSV/JSON/Parquet files directly with zero load step, persisting results to local database files, working with nested JSON and struct/list columns, advanced SQL (window functions, PIVOT/UNPIVOT, date/time functions), DuckDB's Python/pandas/Arrow integration, and — once the course turns to performance and larger-than-memory data — querying the NYC TLC yellow taxi trip records over HTTP, profiling and fixing a genuinely slow query, and building real local data apps with Streamlit and Apache Superset. The capstone assembles all of it into one DuckDB analytics pipeline — ingest from CSV, JSON, and Parquet, join, aggregate, and export a verified report — entirely on your own machine.

Before you start

What you'll be able to do

  • Install and run DuckDB from both the CLI and Python, on any platform
  • Query CSV, JSON, and Parquet files directly with SQL — no load step, no separate database server
  • Join, aggregate, and profile queries with window functions and EXPLAIN
  • Build real local data apps and dashboards with Streamlit and Apache Superset

Prerequisites

  • No Python needed for Modules 1–6; basic Python is recommended from Module 7 onward, where the course moves into pandas, Polars, and Python pipelines
  • No prior SQL or database experience required — this course teaches the SQL it needs as it goes
  • A working command line and a code editor
  • Docker Desktop (or Docker Engine on Linux), but only for two lessons in Module 10 — skip them and the rest of the course is unaffected

Tools you'll use

  • DuckDB
  • SQL
  • Python
  • Streamlit
  • Apache Superset
  • Docker

Before you start

No prior SQL or database experience is required — this course teaches the SQL it needs as it goes, in plain English. Basic Python is helpful but not required, and a working command line is all the setup you need. No cloud account and no GPU are needed anywhere in this course; DuckDB's hosted product, MotherDuck, only ever comes up as an optional thing to explore later.

Set up your environment

Everything in this course runs for real, locally, on your own machine — no cloud account, nothing to pay for.

  1. DuckDB CLI — a single install command for your platform, covered fully in Module 1.
  2. DuckDB's Python package — a single pip install duckdb, verified in Lesson 3.

Every SQL query and every piece of output you see was actually run against the real, installed tool — nothing is simulated or invented. The one named exception: this course's install steps for Linux and Windows are verified correct against DuckDB's own documentation, not independently captured on those platforms — said plainly wherever it applies, starting in Module 1.
