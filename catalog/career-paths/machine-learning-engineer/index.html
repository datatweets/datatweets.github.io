Machine Learning Engineer Career Path

A complete, free path from Python foundations through classic machine learning and into deep learning — building real models at every step.

Go from your first line of Python through the classic machine learning toolkit and all the way into deep learning. You'll train and interpret real models, then build and ship neural networks with both PyTorch and TensorFlow — with a guided project at nearly every step.

What you'll learn

  • Python and the ML ecosystem (NumPy, Pandas, scikit-learn)
  • The math behind the algorithms — calculus and linear algebra
  • Regression, classification, trees, and ensembles
  • Unsupervised learning, clustering, and feature engineering
  • Rigorous model evaluation and optimization
  • Deep learning with PyTorch and TensorFlow
  • Computer vision (CNNs), sequence models (RNNs), and NLP
