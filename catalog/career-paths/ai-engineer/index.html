AI Engineer Career Path

A complete, free path to an AI engineer role — Python, then the full Generative AI & LLM Engineering stack: prompting, tools, RAG, agents, and deployment.

Become the engineer who ships AI features. Start with Python, then build the entire modern LLM stack hands-on — prompting, tool use, the Model Context Protocol, embeddings, vector databases, retrieval-augmented generation, autonomous agents, LangChain and LangGraph, and production deployment — every concept verified with real, runnable code on Claude.

What you'll learn

  • Python programming, the language of AI engineering
  • How LLMs work and how to call them from code
  • Prompt engineering and structured outputs
  • Tool use, function calling, and the Model Context Protocol
  • Embeddings, vector databases, and semantic search
  • Retrieval-augmented generation (RAG) over your own data
  • Building autonomous agents, with and without frameworks
  • Shipping reliable, affordable, secure AI services

Your learning path

Work through the phases in order. Each card is a full course you can start right now.

Phase 0 — Working With AI (no code)

Optional but recommended. Learn to direct AI in loops before you write a line of code — the mindset every AI engineer relies on.

Beginner Loop Engineering: Get AI to Finish the Job Go past one-shot prompting: run an AI in a loop that attempts, checks its own work, corrects, and stops — in ChatGPT, Claude, Claude Code, and Codex.
