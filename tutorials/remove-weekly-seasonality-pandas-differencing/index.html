How to Remove Weekly Seasonality with pandas Differencing

A beginner-friendly guide to comparing each daily value with the same weekday one week earlier, checking what the transformation removed, interpreting event echoes, and reconstructing the original scale.

Mehdi Lotfinejad
August 5, 2026 · 10 min read

A fictional shared workshop used 220.7 kWh on one Tuesday and averaged 161.2 kWh on Saturdays. Subtracting adjacent days would mix the regular weekday pattern with the week-to-week change we want to study. The better comparison is Tuesday with the previous Tuesday, not Tuesday with Monday.

To remove a fixed weekly pattern from complete daily data in a pandas Series, calculate series.diff(periods=7). Each result is the current value minus the value on the same weekday one week earlier. Keep the date index aligned, expect the first seven results to be missing, and restore the original scale with difference + series.shift(7).

This lesson builds that calculation around fictional workshop electricity use. We will verify what disappeared, what remained, and why one unusual event creates two notable points in the transformed series. If you first need practice parsing and checking date columns, start with How to Work with Dates in pandas.

Understanding the same-weekday subtraction

Seasonality is a pattern that repeats at a regular interval. Here, equipment is usually active on weekdays and quieter on weekends. The interval, also called the period, is seven observations because the data contains one observation per calendar day.

A seasonal difference subtracts an earlier value at that period:

Suppose the two most recent Tuesdays used 216.7 and 220.7 kWh. The second Tuesday’s seasonal difference is 220.7 - 216.7 = 4.0 kWh. Both values include the normal Tuesday operating pattern, so subtraction cancels most of that shared level.

The result has a different meaning from the original series. An original value answers, “How much electricity did the workshop use?” A seven-day difference answers, “How much did use change from the same weekday last week?” Positive means higher than one week earlier. Negative means lower.

This operation does not automatically remove every time-dependent pattern. A long-term rise can remain as a positive weekly change. Events, random variation, changing seasonal strength, and a second calendar cycle can remain too. Seasonal differencing is a focused transformation, not proof that a series is stationary. In a stationary series, properties such as its typical level, variation, and dependence remain stable over time.

If you need to estimate the weekday pattern instead of transforming it away, see Find Weekly Seasonality in Python with pandas Rolling Windows.

Setup and the teaching dataset

You need Python 3.11 or newer and a way to run a Python file or notebook cell. You should know how to assign a variable and select a column from a pandas DataFrame, which is a table with labeled rows and columns. No forecasting or advanced statistics knowledge is required.

Create an isolated environment, activate it, and install pandas:

On Windows PowerShell, activate the environment with .venv\Scripts\Activate.ps1. The calculations were tested with Python 3.13.2 and pandas 3.0.3. The reproducible dataset and figure build also used NumPy 2.5.1 and Matplotlib 3.11.0.

Download workshop_electricity.csv and save it beside your code. It contains 168 consecutive dates, which is exactly 24 weeks, from 6 January through 22 June 2025.

The file is an original synthetic dataset generated with NumPy seed 20260815. Synthetic means that code created the values. The workshop, readings, and extended equipment test are fictional. The data is released under CC0-1.0, so you may reuse it without restriction.

The generator combines a slowly rising level, a gentle six-week fluctuation, a fixed weekday pattern, random variation, and one large electricity increase on 15 April. These choices make the transformation easy to examine. They are not measurements or assumptions about a real workshop.

Verify that the weekday gap became smaller

Restore values to the original scale

A difference is often an intermediate representation. Reports and forecasts usually need kWh, not “kWh compared with last week.” Reverse the subtraction by adding the aligned value from seven rows earlier:

For a forecast of the next seven days, the base values from one week earlier are already observed. Add each predicted seasonal difference to its matching observed base. Beyond seven days, the required base may itself be a forecast, so define that recursive step before evaluating the method.

Keep dates attached during inversion. Adding plain arrays by position can pair a Tuesday difference with a Wednesday base after filtering or sorting. pandas index alignment makes the intended pair easier to audit.

Common mistakes and troubleshooting

Using lag 7 by habit. The lag comes from the sampling interval and the real repeating process. Seven fits complete daily data with a weekly cycle. Hourly data may need 24 for a daily cycle or 168 for a weekly cycle. Monthly data may use 12 for a yearly cycle.

Skipping timeline checks. Seven rows do not equal seven days when dates are missing, duplicated, or out of order. Sort, check duplicates, infer the interval, and decide how unknown readings should be handled before transforming.

Expecting the first week to contain values. diff(7) needs a paired earlier row, so the first seven results are missing. Do not replace them with zero; zero would claim that no week-over-week change occurred.

Applying diff() twice by accident. electricity.diff(7).diff() first compares weeks and then compares adjacent transformed rows. That is a different operation. Add a second difference only when the analysis has a clear reason and validation supports it.

Calling the result fully stationary. A reduced weekday pattern does not prove a stable mean, variance, or relationship across all dates. Inspect the remaining series and use tests or models that match your actual goal.

Reading an echo as a new event. A one-date spike enters the current side of one subtraction and the earlier side of another subtraction seven days later. Inspect both source dates before explaining a transformed outlier.

Forgetting the original scale. A predicted difference is not a predicted electricity reading. Store the lag, base date, and base value needed for inversion with every forecast.

Using additive differences when the seasonal swing grows with the level. This lesson subtracts kWh because its constructed weekday effects are roughly constant in kWh. If seasonal movement grows in proportion to the level, explore a log scale or another model and validate the choice on your data.

Recap: compare like dates, then keep the pairing

Seasonal differencing changes a level into a matched change. For complete daily data with a weekly pattern, electricity.diff(7) compares each date with the same weekday one week earlier. The first seven results are unavailable because no paired week exists inside the file.

In the executed workshop series, the span of weekday means falls from 86.05 kWh to 0.35 kWh. That shows the fixed weekly level was largely removed. A slow positive change remains, and the fictional equipment test creates a positive difference followed by an opposite echo one week later.

The reusable workflow is short: confirm the calendar, choose the lag from the real cycle, calculate the difference, verify what changed, inspect notable pairs in the original data, and preserve the shifted base for reconstruction. Use the transformed series only when its week-over-week meaning matches the question you need to answer.
